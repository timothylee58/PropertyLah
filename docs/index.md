## How to use these docs

1. **For a pitch:** Start with `PITCH.md`, then `PRD.md` for depth.
2. **For a technical review:** Read `ARCHITECTURE.md` and `DIAGRAMS.md`.
3. **For a live demo:** Follow `DEMO_GUIDE.md` exactly.
4. **For planning:** Open `ROADMAP.md` and update phases as needed.

## Rendering diagrams

All diagrams are written in [Mermaid](https://mermaid.js.org/) syntax. They render automatically in:

- GitHub / GitLab Markdown previews
- Notion (with Mermaid embed)
- VS Code with Mermaid extension
- Obsidian with Mermaid plugin

To export for slides, use a Mermaid-to-SVG/PNG tool or screenshot from a Markdown preview.
